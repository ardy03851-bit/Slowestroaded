# Sports Car model

`quaternius-sports-car.glb` is the original [Sports Car by Quaternius](https://poly.pizza/m/1mkmFkAz5v), distributed under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).

Run `node tools/convert-sports-car.mjs` from the repository to regenerate both OBJ files in `static/media`. The game uses the OBJ files at runtime, with four individually pivoted wheels and separately named front and rear light meshes.
